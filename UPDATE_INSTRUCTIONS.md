# Updating the GitHub repository

This ZIP is a complete repository snapshot based on GitHub `main` commit
`7e4a17e7fa8de859660694fef85ecd0990a9f577`, with v0.9.24-v0.9.32 added.

1. Extract the ZIP.
2. Copy its contents into a new branch of `papasop/Geometric-Flow`.
3. Commit the changes and open a pull request into `main`.
4. Wait for all repository checks to pass before merging.

Suggested PR title:

`Add v0.9.32 fourth-chart signed endpoint milestone`

exploratory scripts.
