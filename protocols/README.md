# Protocol Records

This directory is reserved for stable, repository-level protocol navigation.
The current frozen protocol records remain at their historical paths and are
referenced from `audit/artifact_manifest.json` and
`audit/claims_manifest.yaml`.

External auditors should not infer a protocol from README prose or console
logs. A protocol is auditable only when it is represented by a repository file
with a recorded SHA-256 binding and an explicit claim relationship.
